## 🌱 Overview
RishtaNAMA is an AI-powered Streamlit app for generating **matchmaking profiles, captions, and suggestions**.  
Write your intent, AI generates meaningful content in real-time.

---

## 🚀 Features
- 🖥️ **Interactive UI** via Streamlit  
- 🔗 **AI-powered content** (`openrouter_api.py`)  
- ✍️ **Profiles, bios & captions generation**  
- 📌 **Easy to extend & customize**
